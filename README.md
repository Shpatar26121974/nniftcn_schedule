# Розклад занять — ННІФТКН ЧНУ

React-застосунок для перегляду розкладу ІІ семестру 2025–2026.

## Запуск

```bash
npm install
npm start
# → http://localhost:3000
```

## Збірка

```bash
npm run build
# файли в build/ — кладіть на будь-який веб-сервер
```

## Логіка тижнів

| Ситуація | Результат |
|----------|-----------|
| Є `1-й тижд.` і `2-й тижд.`, обидва мають предмет | Різні заняття |
| Є роздільник, `2-й тижд.` порожній для групи | Щотижня (1-й тиждень) |
| Роздільника немає | Щотижня |
| Є лише `2-й тижд.` | Тільки 2-й тиждень |
